# 对标拆解与原创迁移

把“说什么”和“怎么说”分开：学习表达功能，用自己的证据重新实现。
拆解产物应让人知道具体哪里可学、为什么可能有效、换场景后哪里会失效。

## 输入与访问

使用用户提供的正文、转录、画面描述和指标。
只有链接时，先用现有工具获取可访问内容；不能访问就说明缺口，索要转录或关键片段。
只看文字只能分析文案；未看到画面、未听到声音，不声称完成视听分析。
用户只要求拆解时不额外生成改编稿；要求迁移时再使用其素材。

## 选择对标

若提供多个候选，比较受众处境、表达目的、制作条件和可观察反馈。
优先选择能理解制作过程、且自己有条件实现的样本。
低粉高赞可作为候选信号，不能排除投流、历史积累、热点或异常样本。
不要仅凭播放量认定方法有效，更不要把热门题材的需求等同于用户有能力交付。
没有数据时可以分析设计，但“有效”只能写为待验证解释。

## 先拆观众，再拆形式

先回答：谁会在什么时刻觉得这与自己有关？
找到具体证据：一句话、一个动作、一段场景。不要只贴“共鸣”“焦虑”标签。
代入可能来自正在经历的情境、身份认同、对他人感受的理解。
不要求作者必须亲历每个题材；叙述立场需准确，观察不能冒充亲历。
然后检查：观众带走什么？知道一个事实、获得一个动作、理解一种处境，还是只有情绪刺激？

## 双层拆解

按自然段或真实时间点分解；没有时间戳时用段落编号，不捏造秒数。
每个关键节点记录：

| 字段 | 说明 |
| --- | --- |
| 可观察内容 | 原句的短摘或画面描述，标位置 |
| 表达功能 | 承诺、举证、反转、演示、限制、行动等 |
| 受众反应假设 | 为什么这类人可能继续看，不写读心结论 |
| 后续兑现 | 前面提出的疑问在何处回答 |
| 失效条件 | 换受众、证据不足、承诺过度时会怎样 |

有视频材料时分别看画面、声音、文案的分工。
区分“吸引停留”“解释可信”“促使行动”，不把所有功能都归给开头。
查看结尾是否给到可带走的价值，而非只有关注口号。
不把原作者成功复述为算法内幕或心理学定律。

## 迁移到自己的内容

1. 抽象机制：用自己的话描述表达功能，不保留标志性措辞。
2. 匹配素材：找用户真实案例、自己的数据、可追溯知识支持同一功能。
3. 检查缺口：是否缺场景、证据、结果或适用条件；缺什么就补采什么。
4. 重建顺序：根据自己的因果链组织，不逐句替换原作名词。
5. 适配形式：能力不足时降低拍摄复杂度，不降低事实可信度。
6. 给出差异：列出沿用的抽象机制、替换的证据、真正新增的观点和仍待验证的假设。

若用户没有素材，可交付新的选题角度与采集清单，不生成假的个人故事。
若为练习临摹，可用用户自有或适合复用的材料练节奏；公开交付版本重新写表达与证据。
素材被广泛讨论不代表其文案、画面、声音可任意搬用；不自动下载剪辑或发布第三方作品。

## 最小迁移实验

用户需要验证时，选一个可解释的表达变化，例如先给演示再解释。
保留目标受众与核心价值不变，记录原版与改版区别。
写下预计影响哪个指标或哪种反馈，以及什么结果会推翻该解释。
不要求每次都严格“80%不动20%创新”；受众或素材变化时，明确可比性不足。
跨账号比较只能启发假设，不构成控制实验。

## 交付物

- 一句话定位：给谁、在什么情境、交付什么。
- 关键节点拆解表，证据与推测分列。
- 可迁移机制及不适用条件。
- 需要改编时交付新稿/镜头草案与来源差异说明。
- 需要验证时加下一轮实验卡，不擅自发布。

## 验收

能否用具体内容解释机制，而不只是给“痛点—共鸣—方案”贴标签？
迁移稿移除原作者标志性词句后，是否仍有独立信息价值？
每个个人事实是否来自用户，每个外部观点是否保留出处？
是否把人群、场景与制作能力变化对结果的影响写清？
有多少结论只是文本分析，是否错误声称得到后台数据验证？
