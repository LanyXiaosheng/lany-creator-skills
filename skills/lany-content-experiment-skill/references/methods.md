# 内容切片与复盘工作指南

本指南把项目记录转为选题，并用可比较的观察更新内容假设，可独立使用。
内容指标用于判断表达和需求线索，不能直接证明成交或交付价值。

## 1. 找一件可复述的事情

从项目记录取一个动作、一个困难或一次判断变化。
先写事实句，再写观点；无法指出发生过什么时，先补记录而不是扩充选题。
按步骤、卡点、认识变化寻找切片，每片需独立解决一个问题。
同一个事实换标题不算新切片；没有独立动作或证据时合并。

| 字段 | 填写内容 |
| --- | --- |
| 观众任务 | 谁在什么场景需要这条内容 |
| 一句话问题 | 这条只回答什么 |
| 事实证据 | 操作记录、截图、原话或结果 |
| 可带走动作 | 看完可以开始的一步 |
| 尚未确定 | 哪个解释或结果需要继续观察 |

## 2. 指标先定义再计算

每个指标记录名称、分子、分母、来源、观察窗口和是否投流。
播放次数与观看人数不可互换；缺平台定义时保留原字段，标为不可直接比较。
平均观看时长不等于完播率，收藏次数不必然等于收藏人数。
无法统一定义的作品分别描述，不强行放进排名表。

```text
作品编号与发布日期：
目标与主指标：
分子/分母及平台定义：
统计截至时间和观察窗口：
题材、时长、形式：
投流、热点或其他异常：
可比较的历史作品：
```

分母很小时，一个行为就可能明显改变比例，要同时保留计数。
分母缺失时不得反推转化率；零也要区分“确认没有”与“未采集”。

## 3. 在结果出现前写预测

确定本轮是改善理解、收藏意愿还是有效询问，不用所有指标事后挑赢家。
描述变量到结果的中间路径，例如先展示结果可能帮助观众更早理解用途。
预测允许只是方向，但要写清什么现象会让自己放弃解释。
没有基线先积累描述数据，不随意设置通用达标线。

```text
本轮目标：
基线样本与选择理由：
主要改动：
保持项与无法控制项：
预计改变的行为及理由：
主指标与观察窗口：
辅助反馈：
执行前检查：
继续、换假设或暂停的条件：
```

## 4. 分开三个观察层次

执行检查：计划的变化是否实际呈现，结果画面是否足够清楚？
理解检查：目标用户能否复述问题与方法，在哪一步误解？
分发观察：同口径指标是否变化，流量来源与窗口是否可比？
执行未完成时先修执行，不能评价一个没有真正实现的方案。
同时改标题、题材和开头时，记为组合改版，不归因于其中一个因素。
预算或时间有限时先减少实验数量，保留记录质量。

## 5. 完整虚构练习

以下项目、数字和反馈均为虚构，仅用于演示计算与决策。
项目：整理共享盘，补充日期与状态字段，发现成员仍不清楚谁批准最终版。
可拆两片：如何看文件版本；如何记录最终确认责任。二者各有不同动作，不重复讲命名。
首轮选第一片，面向需要整理团队文件的人。
历史样本均统计发布后48小时，收藏率定义为收藏人数除以观看人数，未投流：

| 作品 | 观看人数 | 收藏人数 | 收藏率 | 形式 |
| --- | --- | --- | --- | --- |
| A | 1000 | 30 | 3% | 先解释概念 |
| B | 800 | 32 | 4% | 先解释概念 |
| C | 1200 | 48 | 4% | 先解释概念 |

汇总描述为110/3000，约3.67%，不直接平均三条百分比。
样本只能描述历史表现，不能证明解释概念是问题。

实验卡实例：

- 目标：让观众更早看懂命名规则的用途。
- 改动：开场先展示混乱与整理后的目录，再解释字段。
- 保持：相近主题、时长和录屏形式，仍按48小时观察。
- 不可控：推荐人群与分发量；记录流量来源变化。
- 主指标：收藏人数/观看人数，同时保留原始计数。
- 预测：可能增加保存意愿；若用户看不清差异，先修画面，不继续换话术。

虚构结果：D有900位观看者、45位收藏者，收藏率5%；两条反馈表示能看清版本差异，一条仍询问谁确认最终版。
结果描述：D比历史汇总比例高约1.33个百分点；只有一个新样本，题材与推荐人群差异仍可能影响结果。
不能得出：新开头必然提升收藏、用户愿意购买、全部用户都理解了内容。
下一轮：在另一条相近教程复验结果展示，单独记录观众是否理解；确认责任问题留作第二片。
若复验无同方向变化，回看执行质量与受众差异，不把D当作永久规则。

## 6. 竞争解释与停止条件

| 解释 | 应找的证据 | 可执行排查 |
| --- | --- | --- |
| 改动没有被看见 | 画面、字幕或理解反馈 | 检查可读性，做理解测试 |
| 题目与受众不匹配 | 评论问题与承诺错位 | 缩小对象或改变问题 |
| 观察不可比 | 时长、窗口、投流、来源差异 | 分开报告，选相近样本 |
| 随机波动 | 样本少、历史幅度大 | 保留不确定性，有限复验 |

重复若干次方向一致仍不等于随机对照证据，可作为有边界的个人经验。
达到用户设定的成本或时间上限时暂停，不为凑结论无限试验。
低播放不自动意味着内容无价值，也不自动意味着平台限制分发。

## 7. 复盘与验收

经验卡记录：条件、改动、观测、竞争解释、失效条件、下一次验证方式。
核对原预测是否保留，不能事后把结果改写成事前承诺。
核对比例都有分母，提升百分比与百分点没有混淆。
结论明确属于事实、假设、个人经验还是暂不可判断。
下一轮只指定一个主要行动，并说明怎样观察是否值得继续。
只在用户授权文档范围保存结果，不自动发帖或写入长期记忆。
