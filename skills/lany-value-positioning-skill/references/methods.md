# 价值定位方法指南

本指南提供可独立使用的定位工作表与判断方法。它帮助形成可检验的假设，不证明任何人已经具备专家资质，也不保证内容增长或成交。

## 何时使用

在候选方向过多、经历无法转成承诺、已有关注却不清楚帮助了谁时使用。
已有清晰定位、仅缺表达稿时，直接处理表达，不重复做定位。

## 1. 把经历拆成可核对的证据

先列最近实际完成的任务，再描述能力，避免从理想身份倒推履历。
每项任务记录本人负责的部分、输入、产物、实际反馈和仍依赖他人的环节。
结果受团队或资源影响时，不把整体成绩全部归于个人方法。

| 证据状态 | 能支持的判断 | 下一步 |
| --- | --- | --- |
| 有产物及使用记录 | 在该场景做过这件事 | 检查换对象后是否可复现 |
| 只有本人回忆 | 可能有相关经验 | 找旧文件或具体过程补证 |
| 只有学习经历 | 有接触该领域 | 做可演示的小任务 |
| 只是愿望或猜测 | 可作为探索方向 | 标为假设，不用于效果承诺 |

证据不必公开；涉及隐私时可用脱敏过程或重新构造的演示说明能力。

## 2. 选择问题，不先选择人设

对每个方向写一个近期问题实例。没有实例就保留为空缺，不编造访谈。
访谈先问发生过什么，再问理想状态，减少礼貌性赞同的影响。

可直接使用的提问：

- 最近一次遇到这个问题是什么时候？当时要完成什么？
- 卡在哪一步？能展示不含敏感信息的产物吗？
- 现在怎样解决？已经投入了多少时间或资源？
- 如果不解决，哪项工作会受影响？
- 哪些部分希望自己处理，哪些愿意接受协助？

原话、观察、推断分别记录。不能由“我很烦”直接推断身份焦虑，更不能替用户诊断心理动机。

## 3. 比较候选切口

用证据缺口比较，不计算任意权重的精确总分。

| 检查 | 可进入试用的条件 | 条件不足时 |
| --- | --- | --- |
| 能力 | 有可演示的处理过程 | 先做一次练习任务 |
| 问题 | 有近期实例或实际卡点 | 先观察真实工作 |
| 触达 | 能找到处于该场景的人 | 先确定接触渠道 |
| 结果 | 产物或变化可被检查 | 缩小到可观察的一步 |
| 成本 | 时间和隐私边界可接受 | 改范围或暂存候选 |

优先试验最容易补齐关键证据的方向，不默认市场最大或话题最热的方向最好。
若目标是学习、表达或公益，仍检查实际帮助，但无需加入收费目标。

## 4. 将定位写成承诺

先写“处理什么输入、交付什么产物”，再决定是否需要更长远的愿景。
把可控制的交付与受外部条件影响的效果分开。
例如可承诺整理行动项，不能仅凭整理能力承诺团队准时完成任务。

可填写定位卡：

```text
对象及情境：
近期问题实例及证据：
当前替代做法：
本人可演示的能力：
用户需提供的输入：
本次提供的过程与产物：
完成标准：
不包含的事项：
尚未证实的判断：
与承诺相关的一句真实识别描述：
```

识别描述选真实工作细节，不依赖猎奇经历、夸张头衔或公开隐私。
如果别人复述后以为你能提供更大范围的服务，就需要缩小措辞。

## 5. 设计能推翻假设的试用

给一份完整的小清单或演示，让合适对象尝试完成一个动作。
只选一个主要观察量，例如“无需额外讲解能否填写核心字段”。
观察窗口取决于场景何时发生；周会工具应跨过一次周会，不能仅看发布当天。
记录接触对象、实际使用、卡点和未使用原因，不把领取当完成。

```text
本轮假设：
试用材料及使用情境：
参与对象如何匹配：
主要观察量：
观察截止条件：
支持假设的证据：
会推翻或缩小承诺的证据：
无反馈时先检查的触达环节：
下一轮只改变的一项：
```

## 虚构演示：从表格经验到服务切口

一位运营助理曾整理两次活动报名表，三位同事提到重复报名难查。
这些材料支持“存在核对麻烦”和“做过整理”，不支持“能提升活动收入”。
候选一是泛运营教学，候选二是报名表查重；后者更容易展示可检查的产物。
定位草案：帮助手工汇总报名信息的活动组织者，输出重复项与待确认项清单。
试用材料使用十行虚构记录，解释同名不同人不能直接删除。
主要观察量是组织者能否按说明区分确定重复与待核对记录。
假设两人领取、一人尝试且误删同名项，结论应是规则存在误用风险，先改标记方式。
不能据此宣称两人已获益，或证明已有付费市场。
以上人物、数字和反馈仅用于演示判断过程。

## 反例与验收

“懂很多工具，所以教所有人提效”缺少情境和证据，应缩到一项任务。
“有一篇高阅读文章，所以定位成立”只有注意力信号，还需观察帮助是否发生。
“自己做成一次，所以保证所有客户成功”越过了可复现性和外部条件边界。
交付前检查：定位卡可追溯事实；承诺可验收；未知项显式保留；试用能产生支持或反证；下一步在可投入资源内。
